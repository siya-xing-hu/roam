# 连续地图浏览设计

日期：2026-09-23

状态：已实施，已通过生产构建和浏览器交互验证。

## 1. 目标与范围

把现有的行政区逐级钻取改为连续地图浏览。点击区域只改变地图视野和主动选中的区域，不更换为孤立的省、市或区县底图。

沿用现有暗色界面、本地行政边界和 `public/data/attractions.json`。不增加道路、商铺、在线底图、后端或高德请求，不修改景点采集脚本和已经生成的数据。

本设计取代第一版设计中关于 ECharts 地图引擎及区域钻取的实现安排。

## 2. 交互规则

- 删除地图上的放大、缩小和复位按钮，保留全国入口、上一级和可点击的行政区域路径。
- 支持鼠标滚轮、触控板、拖动和触屏双指缩放；保持二维、北向上，不启用旋转和倾斜。
- 点击地图上的行政区或路径项，平滑定位到该区域完整范围；视野适配考虑面板遮挡。
- 点击城市后仍可自由缩小到省或全国，也可拖到相邻城市、相邻省份，周边区域不会消失。
- 放大自动显示城市、区县边界与名称，无需先点击它们的父级区域；点击时选取当前位置已展示的最细行政层级。
- 路径表示主动选中的区域及真实行政祖先，不是点击历史。跨省点击时重建正确路径；直辖市不制造重复的市级节点。
- 地图拖动、缩放不改变左右面板的选择、列表、详情和滚动位置。只有主动选择行政区或景点时才更新相应内容。

## 3. 技术选择

使用 MapLibre GL JS 替换 ECharts，保持 Vite、TypeScript 和无前端框架结构。

继续使用 ECharts 虽能实现部分交互，但需要自行维护连续视野、分层加载和地名避让；MapLibre 的地图视野及图层机制更贴合此次需求。无需引入在线瓦片服务或建立瓦片生成系统，直接使用本地 GeoJSON。

地图实例只创建一次。区域定位不销毁实例，不重置整张地图的数据源。移除已不用的 ECharts 依赖和接口，不保留双引擎兼容路径。运行环境需要 WebGL；不支持时明确提示原因。

所有地图数据、样式及中文标注资源在本地处理，不使用外部底图、字形或样式 URL。边界和景点保持现有一致的 GCJ-02 数值，不单独转换其中一类数据；不与其他坐标系的外部底图混用。

## 4. 视野与数据

### 景点

全量景点作为统一点图层，不再以选中区域的行政编码或区域等级阈值过滤地图点位。由地图引擎裁剪视野外点位，拖动和缩放时连续更新，屏幕内跨行政区的景点均可显示。

保留等级颜色。远距离缩小点位并减少文字，近距离显示更多名称；文字避让不能删除景点本身。使用图层绘制，不为每个景点创建 DOM 标记。点击点位仍打开现有详情，且优先于其下方行政区的点击。

### 边界和地名

全国省级边界常驻。根据视野和缩放，按需加载可见省份的市级数据、可见城市的区县数据，并包含适量屏幕外缓冲区域。

初始分层以 MapLibre 缩放级别 6、9 为市级和区县级切换点，在浏览器验证时依据标注密度微调。显示级别由视野决定，与面板选中了什么无关；名称大小、可见性和避让共同控制密度。

已加载边界计算并缓存包围盒、名称和父级关系，供视野相交判断、区域定位和路径构建使用。现有 `index.json` 是采集概况，并不包含设计所需的空间索引，不能假定其中已有包围盒。

地图连续移动时仅节流更新边界需求，不逐帧下载文件或重建数据源；已加载图层随地图视野连续绘制。仅在所需区域集合发生变化时增减下级边界，复用请求与有容量限制的缓存，限制并发加载数量。

### 面板

将“主动选择”与“当前视野”作为两个独立状态。右侧列表保留现有按所选区域组织、排序和查看详情的方式，不因地图移到别处自动替换。左侧图例保留等级说明；区域数量、列表筛选说明明确标记为所选区域的统计，不再表述成地图屏幕内景点总数。

## 5. 模块职责

- `MapView`：MapLibre 实例、图层、文字避让、景点交互、视野事件和区域定位。
- `BoundaryRepository`：本地边界读取、缓存、包围盒和行政父子关系。
- 视野边界控制逻辑：根据视野选择所需文件，节流加载并防止旧请求覆盖新状态；与面板选择逻辑分离。
- `AttractionStore`：保留全量景点及面板区域查询；地图使用全量数据。
- `main.ts`：连接视野事件、区域选择和面板更新，不再以路径最后一项替换地图底图。
- `AppShell`：保留面板与路径点击，删除加减和复位控件，不在地图移动事件中重新生成列表。

## 6. 加载和异常

下级数据加载期间保持已显示地图可交互，不用全屏遮罩阻断拖动。旧视野请求完成后可以进入缓存，但不能拉回地图或覆盖新选择。

部分地区缺少下级边界时保留已有上级边界和景点，不伪造区县，不反复请求已知缺失文件。其他加载失败提供简短提示及重试；重试不清空已有视野和面板内容。

## 7. 验证与交付

不新增测试脚本或测试类。通过生产构建和真实浏览器操作验证：

1. 全国直接滚轮放大，市、区县名称能自动出现，不需要逐级点击。
2. 定位杭州后缩小，能重新看到浙江及邻省；面板仍保持杭州的选择和内容。
3. 从杭州拖到嘉兴、跨省到上海，视野内景点正常出现，不受杭州行政编码限制。
4. 从区县点击路径中的省或全国，正确定位，随后仍可自由拖动、缩放。
5. 连续快速拖动、缩放和跨区点击，无旧请求跳回、地图闪空或整张图重建。
6. 景点点击、列表详情、桌面及窄屏布局正常；无加减和复位按钮。
7. 检查浏览器错误及资源请求，确认没有运行时高德、在线底图或外部字体请求。

性能结论以实际验证为准，不在未测量时承诺固定帧率或提升百分比。
