## 当前未完成部分

坐标采集遇到高德 `10044 / USER_DAILY_QUERY_OVER_LIMIT`，即账号当日调用量超限，已停止网络查询。错误含义见[高德官方文档](https://lbs.amap.com/api/webservice/guide/tools/info)。本地原始响应继续复用，发布时重新检查名称、行政区、类型、分页完整性与 POI 唯一性。

在现有官方名录中，当前有 **10,613** 条尚未发布；以下是本轮 OSM 补缺后的统计，不与此前高德状态重复相加：

- OSM 暂无符合名称、类型和行政区条件的对象：10,273 条。
- 名称或联合景区本身需确认：290 条。
- OSM 存在多个地点候选：44 条。
- 与已有地点可能重复：6 条。
- 原有明确跳过的 24 条记录继续保留，不重新标为已确认。
- 上述待发布统计不包含已发布旧记录；旧数据的坐标质量不能因本轮保留而视为全部重新核验。
- 北京、江苏、安徽、云南、青海、海南尚未接入完整省级增补名录；已尝试的官网入口存在访问限制、链接变更、证书问题或动态数据待解析。上海沿用原有地方名录。
- 新疆当前增补来源只覆盖 4A；其他省份也以表内来源日期为准，旧名录不等于当前实时等级。未评级景点及港澳台旅游地点尚未系统补齐。

完整本轮待处理项在 `tools/attraction-generator/tmp/expansion/osm-publication.json`；此前高德查询状态仍保留于 `publication.json`。原始文件、全国 PBF、匹配证据和断点均保存在 Git 忽略的 `tools/attraction-generator/tmp/`。复跑方法见[采集说明](../tools/attraction-generator/README.md)。本次未再次调用高德，也未设置定时任务。

## 本轮坐标来源与核验

- 下载 [Geofabrik 中国 OSM 离线快照](https://download.geofabrik.de/asia/china.html)，按现有名录提取名称候选；全国匹配得到 1,758 条唯一/同一范围内匹配，其中包含已有点，最终新增 1,153 条。
- 新点中 957 条采用面范围内代表点，196 条采用 OSM 标注点。保留原始 WGS84 坐标、OSM 对象链接、原始标签、面几何及文件 SHA-256。面代表点不等于景区入口；地图详情已说明。
- 统一转为 GCJ-02，重新按前端同一套省、市、区县边界定位；名称、行政区不符、多候选、附属设施、镇村中心和单纯山峰不直接发布。边界缺失或贴近边界的点会保守留待核实。
- OSM 衍生坐标保留 [OpenStreetMap 署名与 ODbL 许可](https://www.openstreetmap.org/copyright)，官方来源继续用于景区名称和等级。
- 广西官方名录 699 条中，697 条有可解析经纬度，但坐标系未声明，暂不直接用于地图。审核得到 693 条待确认坐标系、2 条不在已加载边界内、2 条地区疑似不符、2 条缺失/无效坐标；有 12 条记录共享坐标。其中广西“九龙瀑布群”的原坐标落在云南罗平。审核文件为 `guangxi-coordinate-audit.json`，转换假设仅供核对，不自动猜测坐标系。
